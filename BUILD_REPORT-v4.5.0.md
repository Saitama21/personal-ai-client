# Отчёт сборки v4.5.0 — CK52DWY Knowledge

## Основание

Клиент перестроен под подтверждённую по фотографиям конфигурацию:

- Tengyue / Dongguan Xinrui CK52DWY;
- SINUMERIK 828D-TE42;
- CNC V04.95 + SP03 + HF02;
- Operate 04.95.03.04;
- PLC HT_20250827_SP4.ptp;
- X/Y/Z, предусмотренная C-ось, приводной инструмент, задняя бабка и 15-позиционная револьверная голова.

## Что встроено

- структурированная локальная база: 142 записи;
- 7 реестров источников;
- 17 инженерных статей;
- 97 G-кодов;
- 28 M-кодов с уровнями доверия и блокировками;
- поиск по базе через интерфейс и API;
- автоматическая подстановка релевантного контекста в анализ чертежей, AI-контур, Stock Removal и чат;
- профиль станка с подтверждёнными и неизвестными параметрами;
- жёсткая блокировка неподтверждённых OEM-команд и автоматического MPF.

## Политика источников

1. NC Programming Manual V4.95 — основной источник синтаксиса.
2. Turning Operating Manual V5.25 — дополнение по рабочему процессу ShopTurn.
3. Diagnostics Manual — стандартные NC/HMI/SINAMICS/PLC аварии.
4. Siemens turn-mill material — TRANSMIT/TRACYL как учебное дополнение.
5. Tengyue SYNTEC и пользовательская M/G-таблица — только справочно, без автоматического исполнения OEM M-кодов.

Исходные PDF и XLSX не копируются внутрь дистрибутива. В клиент встроены структурированные записи и реестр происхождения, чтобы сборка оставалась компактной.

## Проверки

- Python: 77 тестов пройдено.
- Multiprocess CAM: 8 тестов пройдено.
- Recognition crop: 5 тестов пройдено.
- Проверка синтаксиса Python и JavaScript пройдена.
- API базы и профиль станка проверены через FastAPI TestClient.

## Ограничения безопасности

Автоматическая выдача MPF остаётся выключенной до подтверждения заводских лимитов, безопасной парковки, геометрии коллизий и OEM M-кодов механизмов.
