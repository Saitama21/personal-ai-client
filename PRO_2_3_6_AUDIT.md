# Personal AI Client PRO v2.3.6 — Chat File Reference Fix

## Исправлено

- Диалог больше не продолжает Responses API через `previous_response_id` исходного анализа.
- Удалённые временные `file_id` OpenAI больше не вызывают ошибку `404 Files [...] were not found` при следующем текстовом сообщении.
- Контекст сохраняется безопасно: клиент передаёт текст исходного ответа и последние 16 сообщений диалога.
- Фото и выделенная область передаются только в том запросе, где пользователь их действительно прикрепил.
- После успешного ответа текущее вложение очищается; история остаётся текстовой и не хранит OpenAI `file_id`.
- Старые клиенты могут присылать `previous_response_id`, но сервер намеренно не использует его для файловой цепочки.

## Проверка

Добавлен регрессионный тест, который передаёт старый `previous_response_id` и проверяет, что новый запрос OpenAI создаётся без него.
