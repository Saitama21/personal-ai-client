# CHANGELOG v4.4.0

## Добавлено

- Единое CAM-ядро с схемой 2.0.0.
- Многопроходная наружная метрическая резьба X/Z.
- Осевое сверление с клевками.
- AF-фрезерование с индексацией C и рассчитанными X/Z-проходами.
- 3D-съём материала для резьбы, отверстия и AF поверх токарной модели.
- Коллизионная модель по подтверждённым оболочкам.
- Детерминированный SINUMERIK 828D MPF с производственным защитным шлюзом.
- Универсальная PDF-карта инструмента и наладки для ручного ввода.

## Защита от ложных заявлений

- Без паспорта коллизии и MPF заблокированы, но универсальные расчёт/симуляция/PDF доступны.
- Радиальное сверление, Y, непрерывная C и произвольное 3D-фрезерование не заявлены.
