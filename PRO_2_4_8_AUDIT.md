# PRO 2.4.8 Audit

## Изменения
- Переработана карточка установки и операций в Stock Removal.
- Добавлены отдельные группы токарных и фрезерных операций.
- Добавлены оси X/Z/C/Y и приводной инструмент.
- Добавлены условия заготовки, припуска, чистоты, соосности и симметрии.
- Неприменимые группы скрываются по выбранному режиму обработки.
- Значения сохраняются в существующем поле `first_side`, поэтому API и история проектов остаются совместимыми.
