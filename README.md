# Personal AI Client PRO v2.6.0 — Structured Machining Operations

Инженерный клиент для анализа JPG/PNG/WEBP/PDF/SLDDRW, подготовки контура, Stock Removal и переноса данных в SINUMERIK 828D.

## Что добавлено в v2.6.0

- Раздел «Стороны и условия обработки» переработан в технологические группы: установка, токарные операции, фрезерные операции, оси/оснащение и дополнительные условия.
- Для токарного, фрезерного и комбинированного режимов автоматически скрываются неприменимые группы операций.
- Добавлены лыски, карманы, пазы, сверление, развёртывание, зенковка, приводная резьба, оси X/Z/C/Y и приводной инструмент.

### Управление правилами и допусками

- общий переключатель блока правил;
- выбор или отключение каждого распознанного допуска и технического требования;
- «Выбрать всё» и «Включить все отключённые»;
- статус `Активно / Отключено` для каждой строки;
- отключённые правила не передаются в итоговый инженерный контекст, ShopTurn payload и последующие запросы ассистенту;
- состояние переключателей сохраняется в проекте и локальном черновике.

### Полная библиотека резьб

Каталог содержит **507 профилей в 14 семействах**:

- метрическая ISO, крупный и мелкий шаг;
- BSPP `G`;
- BSPT `R / Rc / Rp`;
- `NPT / NPTF`;
- `UNC / UNF / UNEF / UNS`;
- трапецеидальная `Tr`;
- упорная `S`;
- круглая `Rd`;
- прямоугольная;
- модульная;
- `PG`;
- Edison `E`;
- API и специальные шаблоны, включая ACME.

Доступны поиск, вкладки семейств, фильтры по диаметру и шагу/TPI, выбор наружного или внутреннего исполнения, ввод класса допуска, карточка стандарта и добавление выбранной резьбы в проект. Распознанную резьбу можно сопоставить с библиотекой или добавить все распознанные позиции.

> Каталог является инженерным справочником. Перед изготовлением специальные, API, трубные и посадочные резьбы необходимо сверять с исходным стандартом и контрольными калибрами.

### Фаски

- раздельный ввод размера и угла: `[1] мм × [45] °`;
- общий переключатель фасок и индивидуальное включение каждой точки;
- компактная компоновка без горизонтального вылета;
- мини-чертёж вынесен в раскрываемый блок;
- совместимость со старыми обозначениями `1×45°` сохранена.

### Адаптивность

- исправлен горизонтальный вылет инженерной панели;
- сетки используют `minmax(0, 1fr)` и безопасное сжатие колонок;
- отдельные компоновки для ноутбука, планшета и телефона;
- библиотека профилей прокручивается внутри карточки и не раздвигает страницу.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Для тестового режима:

```bash
MOCK_MODE=true uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Проверка

```bash
PYTHONPATH=. pytest -q
node --check app/static/app.js
python -m py_compile app/main.py app/thread_library.py
```
