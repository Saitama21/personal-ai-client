# CNC Trainer PRO v0.3.0 — Stage 2

Railway-ready учебный 3D-симулятор токарно-фрезерного станка Tengyue CK52PT-Y с логикой SINUMERIK 828D / ShopTurn.

## Этап 2
- 3-кулачковый патрон слева;
- заготовка направлена вправо;
- 15-позиционный револьвер справа;
- анимированная индексация T1–T15;
- движение револьвера по X/Z/Y;
- вращение шпинделя с привязкой к RPM;
- настройка диаметра и длины заготовки;
- три режима: точение, сверление, фрезеровка;
- адаптивный интерфейс;
- Railway healthcheck `/api/health`.

## Локальный запуск
```bash
npm install
npm run dev
```

## Railway
Build: `npm run build`
Start: `npm start`
