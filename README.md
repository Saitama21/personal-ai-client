# Personal AI Client PRO v5.2.0 — CK52PT-Y Professional Digital Twin

# Personal AI Client PRO v4.8.2 — CK52PT-Y Clamp Setup Simulator

Специализированный CNC‑клиент под фактическую конфигурацию станка **Zhongshan Tengyue CK52PT‑Y** со стойкой **Siemens SINUMERIK 828D PPU271.4**, CNC‑ПО **V04.95 + SP03 + HF02** и осями **X/Y/Z/C**.

## Интерфейс

Интерфейс пересобран в стиле операторской панели SINUMERIK:

- верхняя строка состояния станка;
- вертикальные и нижние softkeys;
- экраны Program / Contour / Cycles / Tool list / Stock Removal / Simulation / Machine / Diagnostics;
- светлая HMI‑область внутри графитового корпуса;
- отдельные MACHINE / ACTUAL VALUES и телеметрия X/Y/Z/C/T/F;
- адаптация под ноутбук, планшет и смартфон.

## Полный технологический мастер

1. Анализ чертежа JPG/PNG/WEBP/PDF/SLDDRW.
2. Инженерная проверка распознанных данных.
3. Заготовка, припуски и базы.
4. Контур X/Z.
5. CAM‑функции XYZC.
6. Револьвер T1–T15.
7. Технологический маршрут.
8. Прогрессивный Stock Removal.
9. Симулятор CK52PT‑Y.
10. Экспорт проекта, PDF‑карты и защищённого MPF.

## Симулятор v4.8.2

### Установка детали и порядок обработки

- патрон и заготовка **зафиксированы слева**;
- для контрольного чертежа **ДПК-5.02.103** автоматически предлагается зажим за цилиндрическую часть **Ø60**;
- длина зажима по умолчанию **5 мм** вычислена из геометрии фланца на чертеже и обязательно помечена как требующая подтверждения оператором по фактическим кулачкам;
- зона зажима отображается отдельно, защищается от Stock Removal и не допускает режущие перемещения внутри неё;
- наружное точение начинается у границы зажима и продолжается к свободному торцу;
- при левом зажиме осевое сверление входит со свободного правого торца, то есть не проходит инструментом через патрон;
- проверяется соответствие диаметра зажима фактическому диаметру контура в точке границы;
- при опасном приближении к зоне кулачков формируется предупреждение;

### Геометрия и операции

- патрон и заготовка **зафиксированы слева**;
- 15‑позиционный револьвер расположен **справа**;
- визуальная индексация T1–T15;
- отдельные модели проходного резца, резьбового резца, отрезного резца, осевого сверла, радиального приводного сверла и концевой фрезы;
- точение и Stock Removal X/Z;
- наружная метрическая резьба;
- осевое сверление с клевками;
- радиальное сверление с индексируемой C;
- AF/лыски/многоугольник с X/Y/Z/C;
- радиальные и торцевые карманы и пазы;
- фрезерование с движением Y;
- отрезка как последняя операция;
- телеметрия, пауза, Cycle Start, Reset, переход по движениям и override;
- WebGL‑3D и функциональный Canvas‑2D fallback для устройств без WebGL.

## Цифровой двойник

Подтверждено фотографиями:

- CK52PT‑Y;
- SINUMERIK 828D PPU271.4;
- MLFB `6FC5370-5AA40-0AA0`;
- CNC `V04.95 + SP03 + HF02`;
- оси X/Y/Z/C;
- 15‑позиционный револьвер и приводной инструмент;
- патрон LEILIKA 03K10;
- задняя бабка;
- инструментальная таблица и экранные формы стойки.

Точные данные, которых пока не хватает для сертифицированной проверки коллизий и автоматического выпуска производственного MPF, перечислены в [`MISSING_MACHINE_DATA.md`](MISSING_MACHINE_DATA.md).

## Безопасность

Геометрическая симуляция работает с параметрами проекта. Однако автоматический MPF остаётся закрыт защитным шлюзом до подтверждения:

- реальных ходов и soft limits;
- размеров патрона, кулачков, револьвера, задней бабки и инструментальных оболочек;
- безопасной парковки;
- OEM M‑кодов;
- запретных зон и PLC‑межблокировок.

Перед станком обязательны **Sinutrain, Dry Run, Single Block, сниженный override и контроль технологом/наладчиком**.
