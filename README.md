# CNC Trainer PRO v0.1.0

Учебный браузерный симулятор токарно-фрезерного станка под логику SINUMERIK 828D / ShopTurn.

## Локальный запуск

```bash
npm install
npm start
```

Открыть: http://localhost:3000

## Публикация через GitHub Desktop и Railway

1. Распакуйте архив в отдельную папку.
2. В GitHub Desktop: **File → Add Local Repository**.
3. Если репозиторий ещё не создан, нажмите **Create a Repository**.
4. Выполните первый commit и **Publish repository**.
5. В Railway: **New Project → Deploy from GitHub Repo**.
6. Выберите репозиторий `cnc-trainer-pro`.
7. Railway автоматически выполнит `npm install` и `npm start`.
8. В Railway откройте **Settings → Networking → Generate Domain**.

Проверка сервера: `/api/health`.

## Что реализовано в v0.1.0

- Правильная компоновка: патрон слева, заготовка вправо, револьвер справа.
- 15 инструментов T1–T15.
- Режимы: токарная обработка, сверление, фрезерование.
- Координаты X/Z/Y/C и ручное перемещение.
- Безопасный/рабочий ход.
- Простая 2.5D симуляция снятия материала при точении.
- Симуляция осевого сверления.
- Упрощённая C/Y-фрезеровка.
- Установка нуля детали.
- Журнал операций.
- Учебное задание и проверка координат.
- Адаптивный интерфейс для ноутбука и планшета.
