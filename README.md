# Personal AI Client PRO v4.5.1 — CK52DWY Knowledge

Версия 4.5.1 перестраивает клиент под фактически подтверждённую конфигурацию станка пользователя:

- **Tengyue / Dongguan Xinrui CK52DWY**;
- **SINUMERIK 828D-TE42**;
- **CNC V04.95 + SP03 + HF02**;
- машинные оси **X/Y/Z**, предусмотренная C-ось, приводной инструмент и задняя бабка;
- 15-позиционный револьвер;
- OEM-циклы и PLC-проект `HT_20250827_SP4.ptp`.

## Локальная инженерная база

В `data/knowledge_base` встроена структурированная база из предоставленных пользователем материалов:

- основной NC Programming Manual **V4.95**;
- Turning Operating Manual с ShopTurn;
- Alarms Diagnostics Manual;
- токарно-фрезерная презентация Siemens по `TRANSMIT` / `TRACYL`;
- Tengyue SYNTEC manual — только как механический справочник;
- пользовательская таблица M/G-кодов.

База содержит:

- профиль станка и список неизвестных паспортных параметров;
- иерархию доверия источникам;
- курированные статьи по ShopTurn, контурам, Stock Removal, инструменту, трансформациям и диагностике;
- 97 G-команд;
- 28 M-команд с уровнями доверия;
- жёсткое правило: неподтверждённые OEM M-коды не превращаются в готовые команды.

### API базы

- `GET /api/knowledge/summary`
- `GET /api/knowledge/search?q=TRACYL&category=all&limit=12`
- `GET /api/knowledge/documents`
- `GET /api/machine-profile`

Контекст из базы автоматически добавляется к анализу чертежа, Stock Removal, AI-контуру и уточняющему чату.

## Интерфейс

В боковом меню добавлен раздел **«База 828D»** с поиском по:

- станку;
- ShopTurn;
- NC;
- токарно-фрезерным функциям;
- инструменту;
- диагностике;
- G- и M-кодам;
- правилам безопасности.

## Безопасность выпуска MPF

Профиль станка считается **частично подтверждённым**, но не полным паспортом. Автоматический MPF остаётся заблокированным, пока не введены и явно не подтверждены:

1. ходы и soft limits X/Z/Y/C;
2. безопасная парковка револьвера;
3. геометрия патрона, кулачков, державок и инструмента;
4. OEM M-коды C-оси, приводного инструмента, патрона, задней бабки и щупа;
5. запретные зоны и межблокировки PLC.

PDF-карта оператора остаётся справочным документом для ручного ввода и проверки на стойке.

## Распознавание

Клиент поддерживает JPG, PNG, WEBP, PDF и SLDDRW. Для растровых чертежей доступно выделение области распознавания. Для PDF и SLDDRW анализируется весь документ.
