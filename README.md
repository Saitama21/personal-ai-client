# Personal AI Client PRO v3.0.1 Local Fallback Fix

Полностью пересобранный клиент с единым workflow: заготовка → AI-данные → контур → инструмент → техпроцесс → Stock Removal → 3D → экспорт.

## Ключевые изменения
- единый интерфейс для смартфона, планшета и компьютера;
- новый восьмиэтапный CAM workflow;
- связывание главного и дополнительных видов;
- разделение токарного X/Z и фрезерных особенностей AF/лысок;
- расширенная телеметрия 3D-симуляции;
- единая экспортная панель SINUMERIK / ISO / отчёт / проект.
