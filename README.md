# Personal AI Client PRO v4.2.0 Operator PDF

Последовательный CNC-мастер: анализ чертежа, проверка, заготовка, X/Z, AF, инструменты, техпроцесс, Stock Removal, 3D-симуляция и экспорт.

## Новое в 4.2.0

- фиксация финального снимка подтверждённых результатов проекта;
- PDF-карта оператора для SINUMERIK 828D / ShopTurn;
- пошаговые сведения: заготовка, базы, контуры, AF/C-ось, T/D, инструменты, режимы, операции и проверки;
- PDF строится строго из `finalResult`, а не генерируется заново моделью;
- любое изменение зависимого этапа сбрасывает финальный снимок;
- режимы в документе помечаются как стартовые рекомендации, требующие проверки оператором.

Railway: `MOCK_MODE=false`, `OPENAI_MODE=live`, `OPENAI_API_KEY=...`.
