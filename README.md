# Personal AI Client

Рабочий MVP веб-клиента для анализа фотографий, PDF и чертежей SolidWorks SLDDRW через OpenAI Responses API с модулем Stock Removal и интерфейсом в стиле Liquid Glass.

## Что уже работает

- загрузка JPG, PNG, WEBP, PDF и SLDDRW;
- выделение области изображения мышью или пальцем;
- отправка изображения, PDF или извлечённого превью SLDDRW в OpenAI;
- автоматическое извлечение встроенного превью и текстовых подсказок из SLDDRW;
- отдельный модуль Stock Removal для заготовки и ориентировочного плана съёма материала;
- тестовый режим без расхода API;
- история результатов в SQLite;
- адаптивный интерфейс для компьютера и телефона;
- удаление временно загруженного PDF из OpenAI после ответа;
- Docker и обычный запуск на macOS/Linux.

## Быстрый запуск на Mac

1. Распакуйте архив.
2. Дважды нажмите `setup.command` и вставьте созданный ключ. Ввод ключа скрыт.
3. Дважды нажмите `run.command` или выполните:

```bash
./run.sh
```

4. Откройте `http://localhost:8000`.

При первом запуске Python установит зависимости в локальную папку `.venv`.

## Запуск через Docker

```bash
cp .env.example .env
# заполните OPENAI_API_KEY и установите MOCK_MODE=false
docker compose up --build
```

## Переменные окружения

| Переменная | Значение |
|---|---|
| `OPENAI_API_KEY` | секретный ключ OpenAI, только на сервере |
| `OPENAI_MODEL` | модель, по умолчанию `gpt-5-mini` |
| `MOCK_MODE` | `true` для теста без API, `false` для реального анализа |
| `MAX_FILE_MB` | максимальный размер файла |
| `KEEP_OPENAI_FILES` | сохранять ли PDF в OpenAI после ответа |
| `DATA_DIR` | папка SQLite и локальных данных |

## Безопасность

Не вставляйте API-ключ в `app.js`, HTML или другой браузерный код. Ключ читается только сервером из `.env`. Файл `.env` уже исключён из Git.
