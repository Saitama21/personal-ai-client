# CNC Trainer PRO v0.2.0 — Stage 1

Первый технологический каркас браузерного учебного симулятора под Tengyue CK52PT-Y / SINUMERIK 828D.

## Реализовано
- React + TypeScript + Vite;
- Three.js WebGL-сцена;
- патрон слева, заготовка направлена вправо, револьвер справа;
- 15 инструментальных позиций;
- базовые координаты X/Z/Y/C;
- ручные перемещения, быстрый/рабочий ход;
- запуск шпинделя и простая анимация;
- три режима: точение, сверление, фрезерование;
- учебное задание и журнал;
- Railway healthcheck `/api/health`.

## Локальный запуск
```bash
npm install
npm run dev
```

## Railway
1. Создать отдельный репозиторий через GitHub Desktop.
2. Опубликовать на GitHub.
3. Railway → New Project → Deploy from GitHub Repo.
4. Build: `npm run build`, Start: `npm start` подхватываются автоматически.
5. Generate Domain.
