# Personal AI Client PRO v4.4.0 Universal Multiprocess CAM

В этой сборке разделены два режима, которые нельзя смешивать.

## 1. Универсальный режим — работает без паспорта станка

Клиент строит и проигрывает единую CAM-траекторию:

- наружное точение X/Z с рассчитанными черновыми и чистовым проходами;
- наружная метрическая резьба 60° с многопроходной X/Z-траекторией, шагом и витками;
- осевое сверление с клевками, стружкоотводом и внутренней геометрией отверстия;
- AF-фрезерование граней при блокирующей индексации C и подачах X/Z;
- прогрессивный 3D-съём материала для всех четырёх категорий;
- PDF-карта оператора: позиция, тип инструмента, назначение, S/F/ap, геометрия, вылет и обязательные проверки.

Эта PDF-карта предназначена для ручного ввода в SINUMERIK 828D / ShopTurn. Она не является NC-программой.

## 2. Станочный режим — только после паспорта

В ядре есть исполняемая проверка коллизий по подтверждённым ограничивающим оболочкам:

- заготовка;
- патрон/кулачки;
- вершина инструмента;
- державка/оправка;
- пределы X/Z/Y/C;
- заданные запретные зоны.

Детерминированный постпроцессор выдаёт SINUMERIK 828D MPF с G0/G1, G33 и `SPOS=AC(...)`. Клевки сверления развёрнуты в явные G0/G1 для детерминизма. Каждое режущее движение должно иметь строку трассировки. Если паспорт, оболочки, M-коды, база, парковка или маршрут не прошли проверку, MPF заблокирован.

### Данные из паспорта CK52PT-Y, которые понадобятся

1. Ходы, мягкие/аппаратные лимиты и направления X, Z, Y, C; нули станка.
2. Кинематическая схема: ось шпинделя, Y, центр револьвера, направления знаков, допустимое индексирование C.
3. Револьвер: число позиций, габариты, запретные соседние позиции, типы приводных блоков, обороты/момент, диапазоны цанг.
4. Патрон и кулачки: диаметры, длины, Z передней/задней плоскости, допустимый вылет заготовки.
5. Системы координат: G54…, X в диаметрах/радиусах, Z0, коррекции инструмента, безопасная парковка.
6. Машинные M-коды: зажим/разжим C, приводной инструмент ON/OFF и направление, охлаждение, зажим патрона, режим шпиндель/C.
7. Доступные циклы и версия опций SINUMERIK 828D/ShopTurn; требования к G33/SPOS.
8. Формат программы: MPF/SPF, имена, нумерация, вызов инструмента T/D, режимы G18/G90/G94/DIAMON, пример штатной программы.
9. Безопасные зоны, ограждения, датчик Renishaw, поддержка задней бабки/противошпинделя и любые OEM-ограничения.

Фото подтверждают модель CK52PT-Y, SINUMERIK 828D и наличие приводных позиций; но не заменяют пункты 1–9.

## Ограничения

- Радиальное сверление заблокировано.
- Y и непрерывная C не реализованы.
- Произвольные карманы, пазы, сверление по PCD, внутренние/трапецеидальные резьбы не заявлены.
- Коллизии проверяются по оболочкам, а не по полной CAD-модели станка.
- Автоматический пуск на станке не выполняется.

## Запуск

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`.
