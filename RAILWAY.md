# Обновление на Railway

1. Замените файлы проекта в GitHub содержимым этой папки.
2. Сделайте Commit в ветку, подключённую к Railway.
3. Дождитесь `Deployment successful`.
4. Проверьте `/api/health`.
5. Обновите страницу клиента через `Cmd/Ctrl + Shift + R`.

Volume должен быть подключён к сервису по пути `/app/data`, а `DATA_DIR` должен равняться `/app/data`.

После обновления до PRO 2.2 новые поля инструмента и ShopTurn сохраняются внутри существующих проектов. Новые переменные Railway не требуются.
