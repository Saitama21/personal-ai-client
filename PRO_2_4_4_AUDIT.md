# PRO 2.4.4 — Split Chamfer Input

## Реализовано

- единое поле `1×45°` заменено на два поля: размер в миллиметрах и угол в градусах;
- обозначение собирается автоматически и сохраняется в прежнем совместимом формате;
- AI-распознавание раскладывает найденную фаску по двум полям;
- поля блокируются для режимов снятия остроты и отсутствия обработки;
- добавлена адаптивная раскладка для мобильных экранов;
- API: `2.4.4-pro`; feature flag: `split_chamfer_input`.
