# Статус русской документации CK52DWY / SINUMERIK 828D

## Готово

- Полностью переведена 19-страничная учебная презентация Siemens по токарно-фрезерной обработке (`TRANSMIT`, `TRACYL`, примеры программирования).
- Сформировано практическое русское руководство оператора CK52DWY / SINUMERIK 828D.
- Сформировано техническое досье цифрового двойника с подтвержденными версиями, конфигурацией, ограничениями и фото-доказательствами.
- 4 973 уникальные страницы шести руководств проиндексированы для полнотекстового поиска.
- В клиент встроен перевод выбранных страниц на русский, кэширование и экспорт переведенных страниц в PDF.

## Не завершено

Полный постраничный перевод всех 4 973 страниц еще не выполнен. Это большой корпус, поэтому перевод выполняется контролируемыми блоками через раздел «Цифровой двойник». Переводы сохраняются и затем объединяются в русские PDF.

## Правила применения

- Руководство Siemens V4.95 имеет наивысший приоритет для синтаксиса NC именно этой стойки.
- Руководства V5.25 используются как дополнение к ShopTurn и диагностике; расхождения проверяются по реальному экрану V4.95.
- Руководство Tengyue SYNTEC используется только как механический справочник. Его M-коды и системные процедуры нельзя переносить на SINUMERIK без подтверждения OEM.
