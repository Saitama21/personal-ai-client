# Personal AI Client PRO v2.5.0 — Audit

## Реализовано

- Кнопка «Сформировать план» работает на iPhone/Safari и не перекрывается декоративными Liquid Glass-слоями.
- План формируется по фото/PDF/SLDDRW или без файла — по подробному текстовому описанию.
- AI-контур X/Z по-прежнему требует чертёж, чтобы не создавать ложную точную геометрию из одного текста.
- Добавлена явная клиентская и серверная валидация.
- Для токарного режима обязательны диаметр и длина заготовки.
- Для фрезерного режима обязательны ширина, высота и длина заготовки.
- Результат маркируется как «по чертежу» или «по описанию».
- Сохранены: структурированные операции, маршрут инструментов, ShopTurn Tool Flow, паспорт Tengyue CK52PT-Y, библиотека резьб, допуски, фаски, редактор X/Z, проекты и история.

## Проверки

- `node --check app/static/app.js` — успешно.
- `python -m py_compile app/main.py app/thread_library.py` — успешно.
- `PYTHONPATH=. MOCK_MODE=true pytest -q` — 39 тестов пройдено.
