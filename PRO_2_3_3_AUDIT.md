# PRO 2.3.3 Radio + Checkbox Logic — audit

## Реализовано

- Режим обработки использует radio и допускает ровно один активный режим.
- Доступны: токарный X/Z, фрезерный, комбинированный токарно-фрезерный.
- Комбинированный режим показывает оба набора размеров заготовки.
- Базы и нули используют checkbox с множественным выбором.
- Стороны и условия обработки используют checkbox с множественным выбором.
- Ручные значения «Другая база» и «Другое условие» объединяются с отмеченными вариантами.
- Выбор сохраняется в проектах и снимках истории.
- Старые строковые значения проектов восстанавливаются в новые checkbox-группы, неизвестные значения переносятся в ручное поле.
- Backend принимает `stock_mode=hybrid` и формирует общий токарно-фрезерный план.
