# Personal AI Client PRO 2.3.1 · OpenAI file reference fix

## Причина

После анализа PDF приложение удаляло временный файл OpenAI, но сохраняло `previous_response_id`. При следующем сообщении Responses API мог повторно обратиться к удалённому `file_id` и вернуть 404.

## Исправление

1. Для PDF с `KEEP_OPENAI_FILES=false` API больше не отдаёт клиенту исходный `response_id`.
2. Старые сохранённые цепочки обрабатываются автоматически: при 400/404, связанных с отсутствующим файлом или предыдущим ответом, диалог пересобирается из локального текста анализа и последних сообщений.
3. После восстановления сохраняется новый безопасный `response_id`.
4. Добавлены автоматические тесты сценария с удалённым `file_id`.
