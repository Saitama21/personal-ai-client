# BUILD REPORT — Personal AI Client PRO v4.8.2

## Сборка

**Название:** CK52PT-Y Clamp Setup Simulation  
**Версия:** `4.8.2-clamp-setup-simulation`  
**Контрольная деталь:** ДПК-5.02.103, «Ролік», PE 500.

## Реализованная установка

- Трёхкулачковый патрон расположен слева.
- Заготовка Ø60 соединена с патроном и зажата кулачками в левой зоне.
- Револьвер T1–T15 расположен справа.
- Для ДПК-5.02.103 диаметр зажима автоматически равен Ø60.
- Длина зоны зажима по умолчанию 5 мм; это вывод из чертежа, не реальный обмер.
- Зона зажима защищена от удаления материала.
- Наружное точение начинается на границе зажима Z=-5 в канонической системе и идёт по открытому профилю к свободному торцу.
- Визуальная модель зеркально ориентирована относительно канонического X/Z-контура, чтобы соответствовать компоновке реального станка.
- Осевое сверло Ø12,2 входит со свободного правого торца и движется к патрону.

## Защитные проверки

- запрет режущих движений строго внутри clamp zone;
- проверка Ø зажима по наружному контуру;
- блокировка некорректной длины/диаметра зажима;
- предупреждение, пока оператор не подтвердил фактическую длину зажима;
- пропуск торцевания, если Z0 попадает в защищённую зону;
- сохранение Ø60 в материальной модели внутри clamp zone.
