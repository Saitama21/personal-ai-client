# PDF-карта оператора SINUMERIK 828D / ShopTurn

Этап «Экспорт» теперь работает через финальный снимок проекта.

1. Завершите этапы 1-9.
2. Подтвердите просмотр симуляции до 100%.
3. На этапе 10 нажмите **«Зафиксировать итог»**.
4. Нажмите **«PDF для стойки 828D»**.

PDF формируется строго из `finalResult`: подтверждённых размеров, заготовки, баз, X/Z, AF, инструментов, режимов, маршрута, Stock Removal, симуляции и предупреждений.

При изменении зависимого этапа финальный снимок сбрасывается. Его нужно сформировать заново.

Режимы резания в PDF являются стартовыми рекомендациями. Перед запуском обязательны проверка T/D, коррекций, зажима, X0/Z0, графическая симуляция, Dry Run / Single Block и контроль первой детали.
