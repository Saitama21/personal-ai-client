# CK52DWY / SINUMERIK 828D Knowledge Base

Локальная база проекта.

- machine_profile.json — подтверждённые данные стойки и неизвестные паспортные параметры.
- documents.json — источники и иерархия доверия.
- entries.json — курированные инженерные правила.
- g_codes.json — G-команды из таблицы пользователя.
- m_codes.json — M-коды с уровнем доверия.

OEM M-коды не превращаются в исполняемые команды без подтверждения.
